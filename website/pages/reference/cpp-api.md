# C++ API

The C++ API reference is generated by Doxygen from the comments in the public headers, with the repository's
`Doxyfile`: the headers of `core`, `render`, `format`, `vcs`, `channel`, `automation` and `screen`.

**[Open the C++ API reference](../api/index.html)**

Start with `affresco::Application` and `affresco::Screen` (`#include <affresco/affresco.hpp>`), as in
[from C++](../tutorials/from-cpp.md). The libraries can also be linked one by one: `affrescoui::render` (windows,
panels, text, drawing), `affrescoui::format` (the screen format and its runtime), `affrescoui::vcs` (version control),
`affrescoui::core`, `affrescoui::channel`, `affrescoui::services`, `affrescoui::net`, `affrescoui::automation`, and
the others under `modules/`, each with a README (`themes`, `data`, `intelligence`, `imaging`, `scene3d`, `export`,
`audio`). The C API, `affresco/affresco.h`, is described in [other languages](../tutorials/bindings.md).
